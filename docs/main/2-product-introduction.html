2. 제품 소개#

VirtOn은 관리자에게 웹 기반 대시보드와 관리 화면을 제공하여 Proxmox VE 환경의 VM/CT, 클러스터, Ceph, HA, 템플릿, 스토리지, 네트워크, 알림, 보안 설정을 통합 관리하도록 지원합니다.

2.1 제품의 구성 및 사양#

2.1.1 제품의 구성#

구성요소

형태

주요 역할

웹 관리 화면(Frontend)

Next.js 기반 웹 애플리케이션

로그인, 대시보드, 인스턴스, 클러스터, 스토리지, 네트워크, 설정 등 관리자 화면을 제공합니다.

보안기능 및 제어 처리 서버(Backend)

NestJS 기반 API 서버

사용자 인증, 권한검사, 보안정책 적용, 감사기록 생성, Proxmox VE 연동을 처리합니다.

Reverse proxy

VirtOn은 별도 전용 하드웨어 없이 서버에 설치하여 운용하는 소프트웨어 제품입니다. 실제 제품 버전, 운영체제 버전, 구성요소 버전은 제출 전 최종 빌드 기준으로 확정합니다.

2.1.3 제품의 외관#

VirtOn은 소프트웨어 제품이므로 전용 하드웨어 외관은 없습니다. 제품 외관은 웹 브라우저에서 제공되는 로그인 화면, 대시보드, 관리 메뉴, 설정 화면으로 확인합니다.

2.2 운용 환경#

2.2.1 제품의 구성도#

VirtOn의 기본 운용 구성은 다음 흐름으로 동작합니다.

구간

연결 관계

설명

관리자 PC → VirtOn Frontend

웹 브라우저 HTTPS 접속

관리자는 브라우저로 VirtOn 웹 관리 화면에 접속합니다.

VirtOn Frontend → Backend

API 요청

화면에서 수행한 조회/제어 요청이 Backend로 전달됩니다.

VirtOn Backend → Database

내부 데이터 저장/조회

계정, 권한, 정책, 감사 로그, 설정 정보를 저장하고 조회합니다.

VirtOn Backend → Proxmox VE

Proxmox API 연동

VM/CT, 노드, 클러스터, 스토리지, 네트워크, HA 등 가상화 자원을 제어합니다.

VirtOn Backend → SMTP 서버

메일 발송 연동

계정 잠금, 보안 경고, 시스템 알림을 이메일로 발송합니다.
