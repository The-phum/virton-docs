# **4. 보안 및 계정 관리**

사용자 계정과 역할, 접근 권한, 보안 정책, 알림 및 감사기록을 관리하는 방법을 안내합니다. 일부 메뉴는 SUPER ADMIN 또는 ADMIN 권한이 있는 사용자에게만 표시됩니다.

## **먼저 확인하세요**

- 계정과 권한을 변경하기 전에 현재 로그인한 사용자의 역할을 확인합니다.
- 보안 정책 변경 전 운영 중인 사용자와 서비스에 미치는 영향을 검토합니다.
- 비밀번호, 복구 시크릿, SMTP 인증정보는 화면 캡처나 문서에 기록하지 않습니다.
