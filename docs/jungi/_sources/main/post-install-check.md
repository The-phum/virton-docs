# **2.3 설치 후 정상 동작 확인**

설치 작업을 마친 후 다음 기준에 따라 VirtOn의 정상 동작 여부를 확인합니다.

| **확인 항목** | **정상 기준** | **실패 시 조치** |
| --- | --- | --- |
| **Restore 작업** | Proxmox 작업 상태가 `Task OK`로 표시됩니다. | 백업 파일 경로, 스토리지 용량, 복구 대상 노드 상태를 확인한 뒤 다시 복구합니다. |
| **네트워크 설정** | 고정 IP, 게이트웨이, DNS 설정 후 관리 PC에서 VirtOn 접속이 가능합니다. | `netplan` 설정값과 브리지/MAC 중복 여부를 확인합니다. |
| **컨테이너 상태** | `docker ps`에서 VirtOn 구성 컨테이너 4개가 실행 중으로 표시됩니다. | 컨테이너 로그와 Docker Compose 설정 파일을 확인합니다. |
| **인증서 등록** | Proxmox API 연동 시 TLS 인증서 오류 없이 연결됩니다. | `/opt/virton/scripts/setup-ca.sh {pve-ip}` 실행 결과와 Proxmox IP를 확인합니다. |
