5. 문제 해결 방법#

본 장은 VirtOn 사용 중 발생할 수 있는 주요 오류와 장애를 기능별로 빠르게 확인하기 위한 요약입니다. 각 기능의 상세 조치 방법은 해당 기능 장의 문제 해결 항목을 함께 확인합니다.

5.1 공통 확인 절차#

순서

확인 항목

조치 방법

1

로그인 세션

세션 만료 또는 권한 부족 메시지가 표시되면 다시 로그인합니다.

2

Proxmox API 연결

[설정] > Proxmox API 연결 설정에서 활성 엔드포인트와 헬스체크 결과를 확인합니다.

3

사용자 권한 및 Pool

기능 버튼이 보이지 않거나 실행이 제한되면 역할 권한과 Pool 할당 범위를 확인합니다.

4

노드/클러스터 상태

대시보드와 클러스터 화면에서 노드 온라인 상태와 쿼럼 상태를 확인합니다.

5

스토리지/네트워크 상태

VM/CT 생성, 백업, 템플릿, 마이그레이션 실패 시 대상 스토리지와 네트워크 구성을 확인합니다.

6

감사 로그 및 작업 이력

설정 변경, 제어 작업, 실패 이벤트는 알림/감사 로그와 Proxmox 작업 이력에서 결과를 확인합니다.

5.3 관리자 통보 확인#

통보 유형

확인 방법

화면 알림

우측 상단 알림 메뉴와 우측 하단 경고 알림을 확인합니다.

보안 경고 목록

[알림] 페이지의 보안 경고 알림 목록에서 계정 잠금, IP 차단, 시스템 경고를 확인합니다.

감사 로그

ADMIN 또는 SUPER ADMIN 계정으로 감사 로그를 조회하여 행위자, 접속 IP, 대상, 결과를 확인합니다.

이메일 알림

SMTP 설정과 사용자 이메일 설정이 완료된 경우 테스트 메일과 실제 보안 이벤트 메일 수신 여부를 확인합니다.
