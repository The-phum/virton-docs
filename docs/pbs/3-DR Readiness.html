3. DR (DR Readiness)#

재해 복구(Disaster Recovery) 관점에서 PBS 백업의 복구 가능 상태를 점검하고, 복구 절차 수행 전 필요한 준비 상태를 확인하는 메뉴입니다.

3.1. 확인 목적#

  • 백업 데이터의 최신성, 검증 여부, 복제 여부를 빠르게 확인합니다.

  • 복구 대상 PBS 서버와 데이터스토어가 정상 연결 상태인지 점검합니다.

  • 실제 장애 상황에서 즉시 복구를 시작할 수 있도록 사전 준비 상태를 확인합니다.

3.2. 운영 포인트#

  • 최근 백업 시점과 마지막 검증 결과를 함께 확인하는 것을 권장합니다.

  • 오프사이트 복제를 사용하는 경우 원본과 대상 PBS 간 동기화 상태를 함께 점검해야 합니다.

  • 복구 전에는 대상 노드, 스토리지, VM ID 충돌 여부를 먼저 확인하면 안전합니다.

3.3. UI 설명#

  • DR 준비 상태 : 실제 관리 대상의 readiness 분포입니다. 총 3개의 상태(준비 완료, 주의 필요, 위험)과 준비 완료 비율을 확인할 수 있습니다.

  • RPO / RTO 현재 추정치 : 마지막 오프사이트 복제 성공 및 복구 테스트 기준으로 자동 산정됩니다. 목표값 설정은 모달 창에서 시간 단위로 숫자를 입력해 저장하면 됩니다. 해당 파트를 통해 현재 RPO와 RTO의 수치 성능을 확인할 수 있습니다.

    1. RPO : 최신 복제 성공 시점을 기준으로 데이터 손실 가능 범위를 추정합니다. 백업을 수행하거나 복제를 수행하면 값을 낮출 수 있습니다. 목표값에 따라 충족, 초과, 미측정 상태를 가집니다. 설정을 하지 않으면 미설정 상태입니다.

    2. RTO : 최근 복구 테스트 완료 시간을 기준으로 복구 소요 시간을 추정합니다. 상태는 RPO와 동일합니다.

  • 보호 대상 현황 : 복제까지 완료된 PBS 백업 목록들입니다. 현제 상태와 상태에 따른 가이드를 확인 가능합니다.

  • DR 이벤트 타임라인 : DR과 관련된 이벤트 타임라인입니다.
