# **1. 시작하기**

VirtOn은 Proxmox VE 기반 가상화 자원을 웹 화면에서 통합 관리하는 소프트웨어입니다. 이 매뉴얼은 사용자가 필요한 작업을 빠르게 찾아 수행할 수 있도록 실제 운영 순서로 구성되어 있습니다.

## **1.1 처음 사용하는 관리자**

다음 순서로 진행하세요.

1. [설치 및 초기 설정](3-installation.md)에서 서버, 네트워크, 권한을 확인합니다.
2. 안내된 제품 설치 절차에 따라 VirtOn을 배포합니다.
3. [로그인 및 초기 설정](2-login.md)에서 관리자 비밀번호를 변경하고 Proxmox VE를 연결합니다.
4. [대시보드](3-dashboard.md)에서 노드와 가상화 자원의 상태를 확인합니다.
5. [보안 및 계정 관리](security-management.md)에서 계정, 권한, 알림 정책을 설정합니다.

## **1.3 사용 전 확인사항**

- VirtOn 접속 주소와 사용자 계정을 준비합니다.
- 수행하려는 작업에 필요한 관리자 또는 사용자 권한을 확인합니다.
- Proxmox VE 연결 상태와 대상 노드의 상태를 확인합니다.
- 운영 환경에서 사용하는 실제 비밀번호와 API Token Secret은 문서나 화면 캡처에 노출하지 않습니다.

제품 식별정보와 구성요소, 운용 환경은 [제품 정보 및 사양](2-product-introduction.md)에서 확인할 수 있습니다. 문서에서 사용하는 전문 용어는 [용어 및 개념](glossary.md)을 참고하세요.
