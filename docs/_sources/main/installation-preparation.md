# **2.1 설치 준비**

설치를 시작하기 전에 대상 환경, 관리자 권한, 배포 구성물을 확인합니다.

| **구분** | **확인 내용** |
| --- | --- |
| **대상 환경** | Proxmox VE가 설치된 서버 또는 클러스터 환경에서 진행합니다. 대상 노드의 CPU, 메모리, 디스크 여유 공간, 네트워크 연결 상태를 먼저 확인합니다. |
| **필요 권한** | Proxmox 백업 복구, 네트워크 설정, 인증서 등록, Docker 컨테이너 확인이 가능한 관리자 권한이 필요합니다. |
| **배포 구성물** | VirtOn 백업 파일, 복구 대상 스토리지, Proxmox 인증서 등록 스크립트, Docker Compose 기반 실행 구성요소를 확인합니다. |
| **비밀정보 처리** | 초기 OS 계정 비밀번호, API Token Secret 등 시험에 필요한 비밀정보는 제출문서 본문에 고정 기재하지 않고 시험기관에 별도 통보한 뒤 시험 종료 후 변경합니다. |
