# **7. 서버 설정 (server)**

![VirtOn PBS 서버 설정](../_static/images/pbs/pbs_server2.png)

PBS 서버를 VirtOn 시스템에 연결하고 관리하는 공간입니다. 다중(Multi) PBS 서버 환경을 지원합니다.

## **7.1. PBS 서버 목록 및 생성 방법**

### 7.1.1 초기 화면

![VirtOn PBS 서버 설정 초기 화면](../_static/images/pbs/pbs_server0.png)

- 처음 서버 설정 페이지로 들어오면 다음과 같이 UI가 출력됩니다.
- 서버 연결 추가 버튼이나 "첫 번째 서버를 연결해보세요" 문구를 클릭합니다.

### 7.1.2 서버 설정 폼

![VirtOn PBS 서버 설정 폼](../_static/images/pbs/pbs_server1.png)

- 서버 연결 추가 버튼이나 "첫 번째 서버를 연결해보세요" 문구를 클릭하면 다음과 같이 UI가 출력됩니다. 다음을 입력하여 서버를 설정해주세요.
    1. **PBS 서버의 IP(Host)** : PBS 생성 시 설정한 PBS 전용 IP 주소
    2. **포트** : PBS 전용 Port 번호 (예: 8007)
    3. **관리자 계정(UserId)** : PBS에서 설정한 유저명
    4. **대상 데이터스토어(기본 Datastore)** : PBS 생성 시 생성한 데이터스토어명
    5. **API 토큰(Token ID/Secret)** : PBS에서 발급받은 토큰 ID와 시크릿 키
    6. **유형** : 저장 유형을 선택 (오프사이트는 미구현 -> 어떤 타입으로 사용할지 지정하는 것에 불과합니다.)

### 7.1.3 서버 설정 후 목록

![VirtOn PBS 서버 목록](../_static/images/pbs/pbs_server2.png)

- **동기화 (Sync)**:
    1. 🔄 동기화 버튼을 누르면 VirtOn 시스템이 PBS 서버에 접속하여 실제 존재하는 스냅샷(백업 파일) 목록과 스토리지 용량을 가져와 DB를 최신화합니다.
    2. 외부(Proxmox GUI 등)에서 발생한 삭제나 변경 사항을 동기화하여 '데이터 불일치'를 방지합니다.

- **활성화 / 비활성화 토글 (Disable/Enable)**:
    1. 버튼을 눌러 특정 서버를 일시적으로 활성화/비활성화할 수 있습니다.
    2. 비활성화 시 백업, 복구, 자동 동기화 등의 모든 쓰기/실행 작업이 안전하게 차단됩니다. 단, 과거의 백업 목록과 작업 이력(Audit)은 조회할 수 있습니다.
    3. 실제 Proxmox VE 클러스터에서도 해당 스토리지가 Disabled 처리되어 불필요한 시스템 리소스 낭비와 에러 로그를 방지합니다.

- **서버 연결 삭제 (Delete)**:
    1. 서버 연결을 영구적으로 삭제합니다. 해당 서버와 연관된 백업 목록 및 과거 작업 이력이 모두 초기화됩니다. (데이터 보존이 필요하다면 '비활성화'를 권장합니다.)
