# **1. PBS 사용법 및 개요**

VirtOn PBS Manager는 Proxmox Backup Server(PBS)와 연동되어 가상 머신(VM) 및 컨테이너(CT)의 데이터 안정성을 보장하는 통합 백업 솔루션입니다.
복잡한 커맨드라인 조작이나 외부 콘솔 접속 없이, VirtOn 대시보드 내에서 원클릭으로 백업 생성, 시점 복구, 스토리지 관리 및 작업 이력 추적을 모두 수행할 수 있습니다.

## **1.1. VirtOn PBS 사용법**

![VirtOn 목록 PBS](../_static/images/pbs/pbs_menu.png)

VirtOn 목록에서 PBS를 선택하면 새로운 창에서 이용이 가능합니다.

> 처음 PBS 파트 대시보드에 들어와 PBS 서버를 설정하지 않으면 아무것도 뜨지 않습니다. 먼저 서버 설정 페이지에서 PBS 설정을 저장해주세요.
