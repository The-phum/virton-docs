# **8. 설정 (settings)**

# 1. 자동 검증 설정 (verify)

![VirtOn PBS 서버 설정](/_static/images/pbs/pbs_setting1.png)

PBS 서버와 데이터스토어별로 정기 무결성 검증 정책을 설정합니다.

## **1.1. 자동 검증 생성 방법**

![VirtOn PBS 서버 설정](/_static/images/pbs/pbs_setting1_modal.png)

- **정책 이름** : 검증 정책 이름을 설정합니다.
- **PBS 서버** : 사용할 PBS 서버를 선택합니다.
- **Datastore** : 사용할 데이터스토어를 선택합니다.
- **주기 및 실행 시각** : 검증 정책을 자동으로 실행할 주기와 실행 시각을 설정합니다.
- **최근 검증 개수** : 한 번에 수행할 검증 개수를 설정합니다.


# 2. 서버 설정 (server)

![VirtOn PBS 서버 설정](/_static/images/pbs/pbs_server.png)

PBS 서버를 VirtOn 시스템에 연결하고 관리하는 공간입니다. 다중(Multi) PBS 서버 환경을 지원합니다.

## **2.1. PBS 서버 목록 및 생성 방법**

### 2.1.1 초기 화면

![VirtOn PBS 서버 설정 초기 화면](/_static/images/pbs/pbs_server0.png)

- 처음 서버 설정 페이지로 들어오면 다음과 같이 UI가 출력됩니다.
- 서버 연결 추가 버튼이나 "첫 번째 서버를 연결해보세요" 문구를 클릭합니다.

### 2.1.2 서버 설정 폼

![VirtOn PBS 서버 설정 폼](/_static/images/pbs/pbs_server_modal.png)

- 서버 연결 추가 버튼을 클릭하면 다음과 같이 UI가 출력됩니다. 다음을 입력하여 서버를 설정해주세요.

    1. **PBS 서버 별칭** : PBS 생성 시 설정할 별칭
    2. **유형** : 저장 유형을 선택 (오프사이트는 미구현 -> 어떤 타입으로 사용할지 지정하는 것에 불과합니다.)
    3. **PBS 서버의 IP(Host)** : PBS 생성 시 설정한 PBS 전용 IP 주소
    4. **포트** : PBS 전용 Port 번호 (예: 8007)
    5. **서버 핑거프린트 신뢰 확인** : 지문 확인을 통해 토큰을 전송하기 전 서버 인증서의 핑거프린트를 확인하고, 사용자가 신뢰한 지문과 일치할 때만 등록이 가능합니다.
    6. **관리자 계정(UserId)** : PBS에서 설정한 유저명
    7. **API 토큰(Token ID/Secret)** : PBS에서 발급받은 토큰 ID와 시크릿 키
    8. **대상 데이터스토어(기본 Datastore)** : PBS 생성 시 생성한 데이터스토어명

### 2.1.3 서버 설정 후 목록

![VirtOn PBS 서버 목록](/_static/images/pbs/pbs_server.png)

- **동기화 (Sync)**:
    1. 🔄 동기화 버튼을 누르면 VirtOn 시스템이 PBS 서버에 접속하여 실제 존재하는 스냅샷(백업 파일) 목록과 스토리지 용량을 가져와 DB를 최신화합니다.
    2. 외부(Proxmox GUI 등)에서 발생한 삭제나 변경 사항을 동기화하여 '데이터 불일치'를 방지합니다.

- **핑거프린트 신뢰**:
    1. 핑거프린트가 신뢰되지 않은 서버라면 신뢰 재검사를 진행할 수 있습니다.
    2. 문제가 없다면 이미지와 같이 신뢰된 서버 지문이라고 출력됩니다.

- **서버 연결 삭제 (Delete)**:
    1. 서버 연결을 영구적으로 삭제합니다. 해당 서버와 연관된 백업 목록 및 과거 작업 이력이 모두 초기화됩니다. (데이터 보존이 필요하다면 '비활성화'를 권장합니다.)
