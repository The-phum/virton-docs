# VirtOn

VirtOn 사용자 매뉴얼 및 제품 설명서입니다. 본 문서는 개요, 제품 소개, 설치 및 배포, 제품 기능 및 사용 방법, 문제 해결 방법을 설명합니다.

## 문서 구성 및 확인 기준

| **구분** | **내용** |
| --- | --- |
| **제품명** | VirtOn |
| **문서 목적** | 관리자와 사용자가 VirtOn을 설치, 접속, 운용, 장애 확인할 수 있도록 권장 목차 기준의 절차와 입력 기준을 안내합니다. |
| **운용 전제** | VirtOn은 Proxmox VE, PostgreSQL, Nginx, SMTP 서버 등 외부 IT실체와 연동될 수 있으며, 각 장에서 필요한 사전 조건을 확인합니다. |
| **보안 유의사항** | 계정 비밀번호, API Token Secret, SMTP 비밀번호 등 비밀정보 원문은 문서 본문에 고정 기재하지 않고 별도 안전 채널로 전달합니다. |
