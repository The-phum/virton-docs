# **3.10 네트워크 (Network)**

네트워크 관리 기능은 **서버의 물리적 인터페이스와 가상 머신(VM) 간의 통신 경로를 통합적으로 설정하고 제어**하는 도구입니다. 복잡한 리눅스 네트워크 구성을 GUI 환경에서 직관적으로 관리하여 인프라의 통신 안정성을 확보합니다.

![네트워크 관리](../_static/images/main/network/network_main.png)

## 사용 전 확인사항

| **구분** | **내용** |
| --- | --- |
| **필요 권한** | 네트워크 인터페이스 생성, 수정, 삭제, 변경 적용은 관리자 권한이 필요한 기능입니다. |
| **영향 범위** | 노드 네트워크 변경은 VirtOn 접속, Proxmox API, VM/CT 통신, 클러스터 링크에 영향을 줄 수 있습니다. |
| **사전 조건** | 대상 노드, 물리 포트, VLAN ID, 게이트웨이, MTU, 브리지 사용 여부를 사전에 확인합니다. |
| **작업 확인** | 변경 후 반드시 Apply Configuration을 실행하고, 노드와 VM/CT 네트워크 연결 상태를 확인합니다. |

## 3.10.1 네트워크 인터페이스 설정

- 네트워크 인터페이스는 **구성되어 있는 클러스터의 첫번 째 노드의 인터페이스** 부터 로드 됩니다.
- **구성되어 있는 클러스터(노드)**를 선택 후 **해당 노드의 네트워크 인터페이스 목록 조회**가 가능합니다.
- **노드 목록이 안보일 시 로그인 재 확인이 필요합니다.`(로그인이 안되어 있을 시 노드 목록을 안보입니다.)`**

## 3.10.2 인터페이스 관리 - 새 인터페이스(네트워크) 생성

![네트워크 생성 브릿지](../_static/images/main/network/network_bridge.png)

### 3.10.2.1 Bridge 타입

- **인터페이스 이름**
  - **영문, 숫자만 생성 가능합니다.**
  - **이름만 입력 후 생성 가능합니다.**
- **Bridge 포트 (선택사항)**
  - **브릿지에 연결할 물리 포트를 선택합니다.**
  - **ex) eth0, eno1, ens1**
- **IPv4 주소/CIDR (선택사항)**
  - **IP주소 입력시 CIDR입력 필수 - \*미입력 시 생성 제한합니다.**
- **게이트 웨이 (선택사항)**
  - **외부 네트워크 접근 필요 시 설정합니다.**
- **댓글 (선택사항)**
  - **사용자의 구분을 위한 Comment(메모)**
- **MTU (선택사항)**
  - **한번에 보낼 수 있는 데이터 패킷의 최대 크기입니다.**
  - **기본값은 1500입니다.**
- **부팅 시 자동 시작 (autostart)**
  - **서버 부팅 시 해당 인터페이스를 자동으로 활성화 하는 기능입니다.**

### 공통 입력값 기준

| **항목** | **입력/선택 기준** |
| --- | --- |
| **인터페이스 이름** | 영문과 숫자만 사용합니다. 중복된 이름은 사용할 수 없습니다. |
| **IPv4 주소/CIDR** | IP 주소를 입력하는 경우 CIDR을 함께 입력합니다. 예: `192.168.0.10/24` |
| **게이트웨이** | 외부 네트워크 통신이 필요한 경우에만 입력합니다. 동일 노드에 중복 기본 게이트웨이가 생기지 않도록 확인합니다. |
| **MTU** | 기본값은 1500입니다. 변경 시 연결된 스위치, NIC, VM 네트워크 설정과 일치해야 합니다. |
| **부팅 시 자동 시작** | 운영에 필요한 인터페이스는 활성화합니다. 테스트용 인터페이스는 운영 영향도를 확인한 뒤 설정합니다. |

### 3.10.2.2 VLAN 타입

- **인터페이스 이름**
  - **영문, 숫자만 생성 가능합니다.**
  - **이름만 입력 후 생성 가능합니다.**
- **VLAN ID**
  - **태그번호 분류 위합니다.**
  - **범위: 1~4094**
  - **기본값: 1**
  - **중복 불가능**
- **VLAN Raw Device(필수)**
  - **VLN이 기반할 물리 포트 입니다.**
  - **포트가 활성화 되어야 합니다.**
  - **하나의 포트에 여러 VLAN 가능 합니다.**
- **IPv4 주소/CIDR (선택사항)**
  - **IP주소 입력시 CIDR입력 필수 - \*미입력 시 생성 제한 합니다.**
- **게이트 웨이 (선택사항)**
  - **외부 네트워크 접근 필요 시 설정합니다.**
- **댓글 (선택사항)**
  - **사용자의 구분을 위한 Comment(메모)**
- **MTU (선택사항)**
  - **한번에 보낼 수 있는 데이터 패킷의 최대 크기입니다.**
  - **기본값은 1500 입니다.**
- **부팅 시 자동 시작 (autostart)**
  - **서버 부팅 시 해당 인터페이스를 자동으로 활성화 하는 기능입니다.**

### 3.10.2.3 Bond 타입

- **인터페이스 이름**
  - **영문, 숫자만 생성 가능합니다.**
  - **이름만 입력 후 생성 가능합니다.**
- **Slaves (선택사항)**
  - **Bond에 포함할 물리 포트들**
  - **최소 2개 필요**
  - **공백으로 구분: `"eth0 eth1"` 또는 `"eth0 eth1 eth2”`**
  - **한 포트는 한 인터페이스만 사용 가능합니다.**
- **Bond Mode (선택사항)**
  - **Active-Backup: 안정성 우선 (권장)**
    - **스위치 설정 불필요**
    - **간단한 구성**
  - **802.3ad (LACP): 성능 우선**
    - **스위치가 LACP를 지원해야 합니다.**
    - **대역폭 증가**
    - **고성능 네트워크용**
- **IPv4 주소/CIDR (선택사항)**
  - **IP주소 입력시 CIDR입력 필수 - \*미입력 시 생성 제한합니다.**
- **게이트 웨이 (선택사항)**
  - **외부 네트워크 접근 필요 시 설정합니다.**
- **댓글 (선택사항)**
  - **사용자의 구분을 위한 Comment(메모) 입니다.**
- **MTU (선택사항)**
  - **한번에 보낼 수 있는 데이터 패킷의 최대 크기입니다.**
  - **기본값은 1500입니다.**
- **부팅 시 자동 시작 (autostart)**
  - **서버 부팅 시 해당 인터페이스를 자동으로 활성화 하는 기능입니다.**

## 3.10.3 문제 해결 방법

| **증상** | **확인 항목** | **조치 방법** |
| --- | --- | --- |
| 노드 목록이 보이지 않음 | 로그인 세션, Proxmox API 연결 | 다시 로그인하고 API 연결 상태를 확인합니다. |
| Bridge 생성 실패 | 이름 형식, 포트 중복, CIDR 형식 | 영문/숫자 이름을 사용하고 물리 포트가 다른 인터페이스에서 사용 중인지 확인합니다. |
| VLAN 생성 실패 | VLAN ID, Raw Device 상태 | VLAN ID가 1~4094 범위인지 확인하고 기반 포트가 활성 상태인지 확인합니다. |
| Bond 생성 실패 | Slaves 개수, 포트 중복, 스위치 설정 | 최소 2개 이상의 물리 포트를 지정하고 LACP 사용 시 스위치 설정을 확인합니다. |
| 변경 적용 후 접속 장애 | 게이트웨이, 브리지, IP 충돌 | 콘솔 또는 Host Shell로 접속해 네트워크 설정을 되돌리고 충돌 IP를 제거합니다. |
| 삭제 실패 | 사용 중인 VM/CT, 클러스터 링크 | 해당 인터페이스를 사용하는 VM/CT와 클러스터 네트워크를 먼저 확인합니다. |
