## **1.2 용어 정의**

| **용어** | **정의** |
| --- | --- |
| **VirtOn** | Proxmox VE 기반 가상화 환경을 웹 화면에서 관리하기 위한 제품입니다. |
| **관리자** | VirtOn의 설정, 계정, 권한, 클러스터, 스토리지, 네트워크 등 관리 기능을 수행할 수 있는 사용자입니다. |
| **Proxmox VE** | VirtOn이 연동하여 VM/CT, 노드, 스토리지, 네트워크, 클러스터 기능을 제어하는 외부 가상화 플랫폼입니다. |
| **VM** | Virtual Machine의 약어로, Proxmox VE에서 관리되는 가상머신입니다. |
| **CT/LXC** | Container의 약어로, Proxmox VE에서 관리되는 컨테이너입니다. |
| **노드(Node)** | Proxmox VE 클러스터를 구성하는 개별 서버입니다. |
| **클러스터(Cluster)** | 여러 노드를 하나의 관리 단위로 묶은 구성입니다. |
| **Pool** | 사용자 또는 역할이 접근할 수 있는 VM, 스토리지, 네트워크 등 리소스 범위를 묶는 단위입니다. |
| **API Token** | Proxmox VE 연동 시 계정 비밀번호 대신 사용하는 인증정보입니다. |
| **감사 로그(Audit Log)** | 사용자 행위, 보안 이벤트, 설정 변경, 실패 이벤트 등을 추적하기 위한 기록입니다. |
