# **2. 제품 소개**

VirtOn은 관리자에게 웹 기반 대시보드와 관리 화면을 제공하여 Proxmox VE 환경의 VM/CT, 클러스터, Ceph, HA, 템플릿, 스토리지, 네트워크, 알림, 보안 설정을 통합 관리하도록 지원합니다.

## **2.1 제품의 구성 및 사양**

### **2.1.1 제품의 구성**

| **구성요소** | **형태** | **주요 역할** |
| --- | --- | --- |
| **웹 관리 화면(Frontend)** | Next.js 기반 웹 애플리케이션 | 로그인, 대시보드, 인스턴스, 클러스터, 스토리지, 네트워크, 설정 등 관리자 화면을 제공합니다. |
| **보안기능 및 제어 처리 서버(Backend)** | NestJS 기반 API 서버 | 사용자 인증, 권한검사, 보안정책 적용, 감사기록 생성, Proxmox VE 연동을 처리합니다. |
| **데이터 저장소(Database)** | PostgreSQL | 사용자 정보, 세션, 권한, 정책, 감사기록, 시스템 설정값을 저장합니다. |
| **접속 보호 및 요청 중계(Nginx)** | Reverse proxy | HTTPS 접속 보호, Frontend 및 Backend 요청 전달을 수행합니다. |
| **배포 구성** | Docker Compose 기반 구성 | 제품 실행에 필요한 컨테이너 구성요소를 구동합니다. |

### **2.1.2 제품의 사양**

VirtOn은 별도 전용 하드웨어 없이 서버에 설치하여 운용하는 소프트웨어 제품입니다. 실제 제품 버전, 운영체제 버전, 구성요소 버전은 제출 전 최종 빌드 기준으로 확정합니다.

| **구분** | **사양/식별정보** | **비고** |
| --- | --- | --- |
| **제품 형태** | 웹 기반 관리 소프트웨어 | 브라우저로 접속하여 사용 |
| **Frontend** | Next.js 기반 | 관리자 웹 화면 제공 |
| **Backend** | NestJS/Prisma 기반 | 인증, 권한, 정책, 감사, 외부 연동 처리 |
| **Database** | PostgreSQL | 제품 운영 데이터 저장 |
| **Reverse Proxy** | Nginx | HTTPS 및 요청 중계 |
| **배포 방식** | Docker Compose 기반 | 구성요소 컨테이너 실행 |

### **2.1.3 제품의 외관**

VirtOn은 소프트웨어 제품이므로 전용 하드웨어 외관은 없습니다. 제품 외관은 웹 브라우저에서 제공되는 로그인 화면, 대시보드, 관리 메뉴, 설정 화면으로 확인합니다.

## **2.2 운용 환경**

### **2.2.1 제품의 구성도**

VirtOn의 기본 운용 구성은 다음 흐름으로 동작합니다.

| **구간** | **연결 관계** | **설명** |
| --- | --- | --- |
| **관리자 PC → VirtOn Frontend** | 웹 브라우저 HTTPS 접속 | 관리자는 브라우저로 VirtOn 웹 관리 화면에 접속합니다. |
| **VirtOn Frontend → Backend** | API 요청 | 화면에서 수행한 조회/제어 요청이 Backend로 전달됩니다. |
| **VirtOn Backend → Database** | 내부 데이터 저장/조회 | 계정, 권한, 정책, 감사 로그, 설정 정보를 저장하고 조회합니다. |
| **VirtOn Backend → Proxmox VE** | Proxmox API 연동 | VM/CT, 노드, 클러스터, 스토리지, 네트워크, HA 등 가상화 자원을 제어합니다. |
| **VirtOn Backend → SMTP 서버** | 메일 발송 연동 | 계정 잠금, 보안 경고, 시스템 알림을 이메일로 발송합니다. |

### **2.2.2 권장 사양 및 최소 사양**

설치 전 아래 항목을 확인합니다. 세부 수치는 운영 환경의 VM/CT 규모, 로그 보관 기간, 동시 사용자 수에 따라 조정합니다.

| **대상** | **최소 확인 항목** | **권장 확인 항목** |
| --- | --- | --- |
| **VirtOn 설치 서버** | CPU, RAM, 디스크 여유 공간, NIC, 운영체제 버전 | 운영 중인 VM/CT 규모와 감사 로그 보관량을 고려한 CPU/RAM/스토리지 확보 |
| **관리자 PC** | 최신 웹 브라우저, VirtOn 접속 가능 네트워크 | 업무망에서 HTTPS 접속 가능, 화면 해상도와 브라우저 호환성 확인 |
| **Proxmox VE 환경** | Proxmox API 접속 가능, 노드/스토리지/네트워크 구성 | 클러스터, HA, Ceph, 공유 스토리지 사용 시 각 기능의 정상 상태 확인 |
| **메일 환경** | SMTP 서버 주소, 포트, 인증 방식 | 보안 알림 테스트 메일 수신 확인 |
| **제품 실행 구성** | PostgreSQL, Nginx, Docker 런타임 구동 가능 환경 | 상세 버전은 제출 전 최종 빌드 기준으로 확정 |

### **2.2.3 제품에 포함된 소프트웨어 목록**

| **구성요소** | **용도** | **비고** |
| --- | --- | --- |
| **Next.js** | 웹 관리 화면 제공 | Frontend |
| **NestJS** | API 서버 및 보안기능 처리 | Backend |
| **Prisma** | 데이터베이스 접근 계층 | Backend |
| **PostgreSQL** | 제품 운영 데이터 저장 | Database |
| **Nginx** | HTTPS 보호 및 요청 중계 | Reverse proxy |
| **Docker Compose** | 제품 구성요소 배포 및 실행 | 설치/배포 환경 |

### **2.2.4 외부 IT실체**

| **외부 IT실체** | **용도** | **설정 위치** |
| --- | --- | --- |
| **Proxmox VE** | VM/CT, 노드, 클러스터, 스토리지, 네트워크, HA 제어 | 로그인 후 초기 설정 또는 [설정] > Proxmox API 연결 설정 |
| **SMTP 서버** | 보안 경고 및 시스템 알림 메일 발송 | [설정] > 이메일 알림 설정 |
| **NFS/SMB/iSCSI 서버** | 외부 스토리지 연동 | [스토리지] > 새 스토리지 생성 |
| **관리자 PC 브라우저** | VirtOn 웹 화면 접속 | HTTPS 접속 환경 |
